# WebGoat Security Lab

## About This Project

This repository documents my hands-on web application security testing and vulnerability analysis using OWASP WebGoat.

WebGoat is an intentionally vulnerable web application designed for learning and practicing web application security.

## Objectives

* Learn practical web application security concepts
* Understand common web vulnerabilities
* Analyze HTTP requests and responses
* Practice vulnerability identification and validation
* Use Burp Suite for web security testing
* Document security findings and remediation techniques

## Lab Environment

* **Application:** OWASP WebGoat
* **Testing Environment:** Local Authorized Lab
* **Operating System:** Windows / Kali Linux
* **Proxy:** Burp Suite
* **Browser:** Firefox / Burp Browser
* **Deployment:** Docker

## Topics Covered

This repository contains my notes, testing methodology, screenshots, and security analysis for the WebGoat lessons I completed.

Topics include:

* HTTP Security
* Authentication
* Authorization
* Access Control
* Input Validation
* SQL Injection
* Cross-Site Scripting (XSS)
* Cross-Site Request Forgery (CSRF)
* XXE
* Session Security
* Other Web Application Security Vulnerabilities

## Methodology

The labs were approached using the following general methodology:

1. Understand the vulnerability
2. Identify the attack surface
3. Analyze application behavior
4. Intercept HTTP requests
5. Modify and test requests
6. Validate the vulnerability
7. Capture evidence
8. Analyze security impact
9. Document remediation

## Disclaimer

OWASP WebGoat is an intentionally vulnerable application created for security education.

All testing documented in this repository was performed against an authorized local laboratory environment.

The techniques described here should only be used against systems for which you have explicit permission to perform security testing.
